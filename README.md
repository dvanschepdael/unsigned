# Unsigned

Unsigned is an experimental C/C99 game engine for Neo Geo AES/MVS, built on top of [ngdevkit](https://github.com/dciabrin/ngdevkit), and inspired by architectural concepts found in modern game engines, particularly **Unreal Engine** and its **Gameplay Ability System (GAS)**.

Concepts such as abilities, attributes, gameplay effects, tags, state-oriented architecture, and separation between reusable engine mechanisms and game-defined behaviour may influence the design of Unsigned, but they are implemented independently for the Neo Geo platform.

Unsigned does not contain Unreal Engine source code and is not affiliated with, endorsed by, or sponsored by Epic Games.

**Unreal Engine** is a trademark or registered trademark of Epic Games, Inc. The names are used here only as descriptive references to the architectural concepts that inspired parts of this project.

## Project status

**Experimental / Active Development**

Unsigned is currently under active development. APIs, architecture, features, and performance characteristics may change significantly.

The project is not yet considered production-ready.
